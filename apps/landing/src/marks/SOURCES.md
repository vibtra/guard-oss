Copied 22 Oct 2026 from `packages/guard-contract/marks/`, **byte for byte**
(the subfolders here mirror that tree). `index.js` carries Guard's generated light-theme rendering of each
(`packages/guard-contract/src/marks.generated.ts`: ids renamed, CSS classes inlined, shapes unchanged). Upstream origins and

**Trademarks.** A file licence licenses no trademark. Each mark is its owner's. The landing shows a mark only beside the
name of the product it identifies (a Service or App row, a provider name, a window titled with that app) — nominative
use, never as decoration, never implying endorsement.
